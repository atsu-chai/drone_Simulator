## 飛行の現実性の向上（2026-11-05、0.7.0）

- ブランチ `codex/realistic-flight-model`。2026-11-06にGitHubへpushし、main向けPRを作成。**統合は未完了**。状態は `git status -sb` とPRで確認する。
- 依頼は「現状を確認し、改善点を洗い出し、より現実に近いシミュレーターを作る」。測定で見つかった差（位置保持の誤差0、周期的に打ち消す流れ、風なし）から着手した。
- 実装：風と突風、GNSS・気圧計・IMU誤差、推定値で動く飛行制御、モーター別推力とミキサー飽和、全傾斜制限、接地反発、消費電力ベースのバッテリー、機体音、吹き流し、屋外の空と草地、機体寸法の縮小、風条件の選択、目視練習。詳細は [物理モデル](physics-model.md)、判断はD005〜D008。
- 実害のあった既存不具合：異常事態のHが中止区画の境界上にあり、数mmの流れで即中止になっていた（D008で修正）。
- Codexの独立調査と差分レビューを実施。調査の指摘のうち斜め入力の傾斜超過と目視練習を採用し、レビューの軽微2件（風向指定時の乱数ずれ、簡易機体のプロペラ対応）を修正。指摘はコードで確認してから反映した。
- 検証（2026-11-05、macOS／Node.js 25.2.1）：`npm test` 全88件成功、`npm run check`、`git diff --check` 成功。風4段階×4科目×seed 3種を検証用パイロットで完走。ブラウザで操縦者・俯瞰・真上、1280×720、見本、実時間の上昇、高度超過の中止、目視練習の切替を確認しエラーなし。
- 開発起動（2026-11-06、D009）：`npm test` 全89件成功、`npm run check` 成功。実サーバーで開発起動は未ログインでも `access:true`・有料モジュール200、通常起動は `access:false`・403のままと確認。ブラウザで異常事態科目の開始を確認。2026-11-06にPRブランチへpush済み。
- 未検証：**人間が風の中で飛べる難易度か**（検証用パイロットは誤差のない位置を読む）。実コントローラーでの操作感、機体音の聞こえ方、実機との一致、Node.js 24での実行。
- 再開地点：`npm run dev`（ログイン不要、D009）で、微風・やや強い風の異常事態科目を人が飛ぶ。難しすぎる場合はIMU誤差と突風を先に調整する。
- 残課題：低fpsで飛行がスローになる（フレーム上限0.1秒）、転倒とプロペラ接触、測位劣化、見本飛行への風と傾きの反映。
