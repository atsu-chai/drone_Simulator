# 公式要件と実装の対応（監修前）

PDFページは表紙を1ページ目とする。以下は対応の入口であり、公式採点の完全実装ではない。

| 要件 | 参照 | 現在の実装 | 残る確認 |

src/training.js の距離閾値1.5m/2.5m、円弧進行許容、各種誤差閾値は練習用代理指標。機体中心を点として扱い、公式の侵入条件を完全再現していない。画面には代理指標で判定する境界を表示する。
独立した指導者の氏名・日付・指摘・解消の記録が揃うまで、公式準拠採点・合格相当とは表示しない。
