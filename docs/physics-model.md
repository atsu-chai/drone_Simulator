## 飛行モード

公式細目の異常事態飛行は「水平方向の位置安定機能OFF」が条件であるため、**高度維持は残し、水平方向だけ補助を外す**。

- 位置保持あり：スティックは速度指令。中立で減速し、推定位置を保持点として固定する。速度の積分項が定常風に対して機体を風上へ傾ける。GNSS誤差を通すためホバリングはわずかに揺らぐ。
- 位置保持なし：スティックは傾斜角の指令。風・慣性・水平レベルのわずかな誤差を止めるものは操縦者の修正だけ。
- 共通：スティック中立で気圧計の値を保持高度にする。全傾斜（前後と左右の合成）に上限がある。

## 変更前後の測定（同一条件の数値実験）

`flightModel.fixedStep`で実際の物理計算を回した値（seed 7・風向90°の1回の試行、2026-11-05）。無風はGNSS誤差の出方で大きくなることがあり、風の強さと単純に比例しない。人間の操縦感の評価ではない。

| 項目 | 変更前 | 変更後 |
| --- | --- | --- |
| 位置保持で60秒手放しの最大ずれ（無風） | 0.0000m | 0.60m |
| 同（平均3m/s・上限付近） | 風なし | 0.36m・0.42m |
| 位置保持なしで手放し | 60秒で1.49m（周期的に打ち消す） | 30秒で 無風22m、平均3m/s 67m、平均4m/s 95m |
| 定常風での傾き | 風なし | 平均3m/sで最大約12° |
| 姿勢の立ち上がり（63%） | 0.45秒 | 0.25秒 |

位置保持なしの無風時の流れはIMU誤差（seed依存）に左右される。

## モデル化していないもの

機体の剛体回転は小角度の近似で、クォータニオンは使っていない（傾斜28°以下の範囲で操作感への差は小さいと判断）。次は未実装：転倒とプロペラ接触、ボルテックスリング、測位劣化やコンパス異常、機種ごとの特性、見本飛行への風の適用、人の目の解像度や周辺視。

検証用パイロットは位置と速度を誤差なしで読むため、風の中で完走できることは**人間が同じように飛べる証拠ではない**。難易度の妥当性は、実コントローラーでの人間の試行と監修者の確認が必要。
