# 参考動画と到達目標

目標：ユーザー指定動画 https://www.youtube.com/watch?v=m9S5KuPaczU と同じ水準の、理解できるCGと実際に操作できる二等実技シミュレーターを完成・検証する。目標は未達成で継続中。

## 確認できた参照情報（2026-10-22）

動画タイトル「ドローン国家試験『二等実技試験をCGで完全解説！』国土交通省」、公開者「山とドローン日記」、長さ5分31秒。ブラウザで動画を再生・シークして観察。
- スクエア：見通しのよい独立した試験フィールド、コーン、進行方向、機体と影、区画の黄・赤の色分け。
- 8の字：中央Hから離着陸、左右のコーンを囲む2円、俯瞰と斜め上のカメラ、機首方向、字幕による説明。
- 操縦者・試験員の位置が分かる。コースと操縦者の距離、寸法を図解できる。
- 実技の3科目を連続した解説として見せる。

映像は以前の制度を扱う説明であり、現在の細則と差がある可能性がある。手順・寸法は現行一次資料を優先し、映像の表現力を目標とする。
一次資料：国土交通省 https://www.mlit.go.jp/koku/content/001971375.pdf （2026年6月5日適用）。PDF物理ページ17・18の図をレンダリングして目視確認。
- スクエア：Aを(0,0)、B(6.5,0)、C(6.5,5)、D(-6.5,5)、E(-6.5,0)。離着陸Hは(0,2.5)。操縦者は最近点から8.5m。
- 8の字：Hを(0,0)、中心(-2.5,0)/(2.5,0)、半径2.5m。操縦者は円の最近点から6.5m、従ってHから9m。
- 異常事態：H(0,2.5)、A(0,0)、左右端±6.5m。Hへ最短経路で高度維持して移動し、その後降下。

## 完了を証明する条件

1. 各科目のコース・H・コーン・操縦者位置を共通定義から生成し、公式図と目視照合済み。
2. 黄の減点区画・赤の中止区画、飛行経路、寸法、機首が読み取れる。
3. 操縦者固定位置・斜め俯瞰・真上の視点を使い分けられる。
4. 3科目の見本飛行を解説付きで再生・停止・再開できる。練習結果と見本の結果を混ぜない。
5. 実操縦でも正しい離着陸地点・高度・順序・2周・側方往復・高度維持の緊急移動を評価できる。
6. 入力表示・校正・切断停止・キーボード補助が動作し、物理を含む再現テストで進行を確認できる。
7. 各科目のブラウザ画像と、全見本の完走・失敗シナリオ・フレームレート差の検証記録がある。
8. 参考映像と実装を横断して比較し、上記の証拠が揃うまで目標を完了としない。

現在の主な差：3科目が同じフィールド上に重なり、8の字のHが遠くに離れている。スクエアのHとAが混同されている。不要なゲート・建物・線が学習を妨げる。俯瞰・見本飛行・区画の面表示がない。

## 進捗：最初の実装（未完了）

- コースを共通定義へ分離し、科目ごとにフィールドを切替。HとAの混同、8の字の中心の位置を修正。
- 面の色分け、円弧・直線と機首方向、寸法、試験員／受験者、ラベル付きコーンを追加。不要なゲート・建物・テクスチャ格子を訓練場から除いた。
- 操縦者位置・斜め俯瞰・真上の3視点を実装。論理座標の右方向と操縦者の画面右を一致させた。
- 3科目・通しの字幕付き見本を追加。再生・停止・シーク・速度変更、任意の合成音声。操作・練習履歴・評価から分離。
- 緊急移動と最終降下を別フェーズにし、高度維持を評価。8の字の機首評価は次の通過点への方向ではなく円の接線へ修正。
- 旧コースの不可視の壁を除去。機体の実際の物理計算を独立モジュールにし、同じ入力での30/60fps一致を確認。
- 自動テスト24件通過（理想航跡での10回完走、3見本と通しの完走・連続位置・高度、物理の一部、サービス回帰）。ブラウザでスクエア・8の字・異常事態の描画と見本、停止とシークを確認。

次に必要な証拠：実際の物理と操縦入力を通した全科目完走・着陸、コーン衝突や危険操作、指示／接地／機首の失敗例、入力表示と操縦支援、表示の重なりと各視点の全科目比較。実機・コントローラーの検証も未実施。動画相当の完成はまだ証明していない。
