## 試験全体（A）

順序：机上 → 口述（飛行前点検）→ 実技 → 口述（飛行後の点検と記録）→ 口述（事故・重大インシデント）。100点からの減点式で70点以上が合格。その日のうちに完了する。保護具（ヘルメット、保護メガネ）を着用する。各科目の開始前に試験員等が風速計で風速を確認する。

| 段階 | 内容 | 制限時間 | 減点 |
| --- | --- | --- | --- |
| 机上 | 模擬飛行計画を提示し4問 | 5分 | 誤答・未回答 1問5点 |
| 飛行空域及びその他の確認 | 空域と周辺、法令違反、携帯書類、体調、気象を答える | 3分 | 点検漏れ10 |
| 作動前点検＋作動点検 | 日常点検記録に記入しながら点検。作動点検の最後に離陸地点直上でホバリングし各舵を確認して着陸 | 通算12分 | 点検漏れ10、記載漏れ・誤り5、軽微な誤り1。飛行前点検を通じて最大の1件のみ |
| 実技 | スクエア 8分、8の字 8分、異常事態 6分 | 離陸指示から着陸まで | 下表 |
| 飛行後点検＋飛行記録 | 点検、日常点検記録、飛行記録 | 通算5分 | 点検漏れ5、日常点検記録5／軽微1、飛行記録10／軽微1。点検系と記録系それぞれ最大の1件のみ。飛行時間の計算誤りは10 |
| 事故・重大インシデント | 6-1 該当する事態を3つ答える、6-2 発生時の処置1問 | 各3分 | 抜け・誤り・未回答 5 |

周囲の安全を確保せず推進系統を作動させて点検すると不合格（A）。

## 口述の実際の手順（Bの実演を基に、項目はA）

様式2の項目は上から順に点検しない。**作動前に見るもの、電源を入れて見るもの、飛ばして見るものに分かれる**（B）。

1. 飛行空域及びその他の確認：試験員の問いに順に答える。法令（今回の飛行に必要な許可の有無）→ 操縦者の体調 → 飛行空域 → 気象（天気、風）。
2. 作動前点検（電源OFF）：機体全般（ネジ、コネクタ、ケーブル）→ プロペラ（外観、損傷、ゆがみ）→ フレーム → 操縦装置の外観・スティック・スイッチ → 機体識別表示（確認して登録記号を用紙に記入）→ 特記：灯火・カメラ等は基本では非該当の扱いがある（B）。
3. 作動点検（地上）：電源系統（送信機→機体の順で電源を入れる）→ 操縦装置のスティックモード → バッテリー（機体、送信機）→ リモートID（非搭載機は正常作動と仮定して点呼。A）→ 灯火、カメラ等。
4. 飛行点検：試験員の指示で操縦装置を持つ。周囲の安全確認を呼称して離陸 → ホバリングして通信系統、推進系統、自動制御系統を確認 → 操縦系統を前進、後退、左旋回、右旋回、上昇、下降などで一つずつ確認 → 着陸地点と周辺を確認して着陸。
5. 記入：飛行で確認した項目（通信、推進、自動制御）を記入し、実施場所、実施年月日、実施者を記入して終了。

呼称の例（B）：離陸前は「前方よし、後方よし、左よし、右よし、足元よし、上空よし、気象よし、モーターを回転させます。離陸します」。着陸前は「着陸地点と周囲の安全を確認しました。着陸します」。到達時は「到達しました」。**試験員に伝えなければ確認していないものとみなす（A 注6）**。

様式2の項目（A）：機体全般、プロペラ、フレーム、通信系統、推進系統、電源系統、自動制御系統、操縦装置、バッテリー・燃料、特記事項。ほかに登録記号、実施年月日、場所、実施者。

様式1の項目（A）：飛行年月日、飛行させた者の氏名、飛行概要、離陸場所、着陸場所、離陸時刻、着陸時刻、飛行時間（分）、総飛行時間、飛行の安全に影響のあった事項、不具合事項。

飛行後（A・B）：機体→操縦装置の順に電源OFF、機器の取付、機体（プロペラ、フレーム、識別票）の外観、発熱、ゴミの付着。結果を日常点検記録へ記入し、飛行記録を作成する。

## 実技の進行（A、Bは指示文の例）

共通：**試験員の指示があるまで移動や姿勢変化をしない**（A）。指示の例は「左旋回で機首をA地点に向け、A地点まで前進してください」（B）。受験者は「移動します」「到達しました」と応答する（B）。各区間の完了ごとに次の指示が出る。

- スクエア（位置安定ON、3.5m）：Hから離陸 → 5秒ホバリング → A → B → C → D → E → A → H → 安全確認 → 着陸。機首は常に進行方向。各点で停止して旋回する。受験者の立ち位置は経路の最近点（A）から手前へ8.5m。
- 8の字（位置安定ON、1.5m）：Hから離陸 → 5秒ホバリング → 指示された向きから連続2周 → 安全確認 → 着陸。円の中心を含まずに周回すると不合格（A）。
- 異常事態（水平方向の位置安定OFF、3.5m）：機首前方で離陸 → 5秒ホバリング → 機首を前方のままAへ → Bへ → Eへ → B…と**1往復以上** → 試験員が任意の時点で緊急事態を宣言 → その場でホバリング → 緊急着陸の指示 → 高度を維持して最短経路で着陸地点上空へ → 安全確認 → 着陸。**宣言と着陸指示は別の2段階**（A）。

区画判定の適用（A 4-3の表）：

| 飛行フェーズ | 不合格区画 | 減点区画 | 直径2mの円 |
| --- | --- | --- | --- |
| 離陸〜離陸地点上空 | － | － | － |
| ホバリング | － | － | ○ |
| ホバリング終了後〜緊急着陸の指示 | ○ | ○ | － |
| 緊急着陸の指示後〜着陸地点上空 | ○ | － | － |
| 着陸地点上空〜着陸 | － | － | ○ |

スクエアのH–A間は四角形の内側の減点区画を判定しない（B）。経路逸脱の救済：区間ごとの初回は、通知後おおむね2秒以内の復帰で減点なし（A）。

## 実技の減点（A）

| 細目 | 点 | 練習での判定（C） |
| --- | --- | --- |
| 不合格区画への進入、制限時間超過、危険な速度（概ね5m/s以上）、墜落、衝突、制御不能、8の字の中心を含まない周回 | 不 | 既存の判定を流用し中止 |
| 飛行経路逸脱：減点区画、ホバリング・着陸時の2m円 | 5 | 機体の半分以上の扱いは中心位置で代理 |
| 指示と異なる飛行：手順、方向、指示前の移動・姿勢変化、2秒以内に復帰しない、継続的な機首違い（8の字は四分円）、明らかに異なる高度 | 5 | 指示待ち中の操縦入力＋移動で判定。風による流れは対象外 |
| 離着陸不良：強い接地、転倒 | 5 | 降下速度で判定 |

| ふらつき（着陸時の滑り含む） | 1 | 突風中は対象外（A 注7） |
| 不円滑：急加減速、急停止、速度が不安定 | 1 | 突風中は対象外（A 注7） |

## 現地の様子（B、映像の観察）

- 土と短い草の開けた場所、背後に低い草地と樹木。
- 地面の白いライン（ロープ）で区画を示す。黄色の小型コーン、青い小旗が境界に並ぶ。赤い円形の離着陸パッド。
- 受験者と試験員はヘルメットと保護メガネを着け、折りたたみテーブルの後ろに並んで立つ。試験員も送信機を持つ（介入用）。
- 用紙はクリップボード。試験員が時間を計る。
- 区画の面を色で塗ってはいない。

## 現行との主な差

| 項目 | 現行 | 本番 |
| --- | --- | --- |
| 全体構成 | 点検→飛行→点検 | 5部構成と各制限時間 |
| 点検 | 6項目を順にクリック | 空域の口頭確認、様式2への記入、電源投入、飛行点検 |
| 実技の進行 | 目標点を自分で順に飛ぶ | 区間ごとに試験員の指示を待つ |
| 呼称 | なし | 離陸前・着陸前の呼称が採点対象 |
| 異常事態 | 固定回数の後に緊急 | 1往復以上の任意の時点で宣言、指示で移動 |
| 採点 | 独自指標 | 細目ごとの減点と70点の模擬判定 |
| 飛行後 | 3項目のクリック | 電源OFF順、点検、様式2と様式1の記入、飛行時間の計算 |
| 事故報告 | なし | 2問 |
| 現地表示 | 色面、HUD多数 | ライン、コーン、旗、赤いパッド。本番では補助表示なし |
| 飛行時間 | 科目ごとに表示 | 開始は離陸指示。残り時間は試験員側で計測 |
