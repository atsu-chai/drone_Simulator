# 表示サイズの確認

リポジトリ直下で `node tests/manual/layout-server.js` を実行し、ブラウザで `http://localhost:8001/` を開く。ポートが使用中の場合は `DRONE_LAYOUT_PORT` で変更できる。

公開用の画面・描画・見本飛行を、1280×720、1024×768、760×1000のiframeで動かす。外枠だけ60%に縮小するため、画像中の文字サイズは通常表示の60%。サイズ選択は同じページの表示領域を変更し、科目選択はページを読み直す。見本を停止して任意時刻・視点を選び、コース端、注記、機体、字幕、操作パネルを確認する。再生中のサイズ変更と拡大枠の切替も確認する。

これは127.0.0.1だけで待ち受ける表示専用サーバー。`/api/status`は常に未契約を返す。公開画面に必要なファイルだけを配信し、非公開の科目実行モジュール、会員・決済・管理APIは提供しない。案内ページなどへのリンクは対象外。通常サーバーの埋め込み禁止ヘッダーやアクセス制御は変更しない。

この確認は認証・課金・実コントローラー・実機操縦の検証にならない。CSS上の表示寸法の確認であり、同じ寸法の実モニターの画素密度・描画性能を証明しない。
