## 起動

Node.js 24系を推奨、24以上が必要です。追加パッケージは不要です。

```sh
npm run setup
npm start
```

`setup` は `.env.example` から `.env` を作成します。既存の設定は上書きしません。`npm start` が `.env` を読み込み、DBは初回起動時に `.data/` へ作成されます。これらは端末ごとの設定・データであり、GitHubには保存しません。

ブラウザで `http://localhost:8000/practice.html`（練習メニュー）を開きます。

3D描画には Three.js を使っています。Three.js本体と追加ローダーはCDNから読み込むため、初回表示時にネットワーク接続が必要です。機体モデルとHDR環境はリポジトリ内に保存されています。

## ログインなしで試す（ローカル開発用）

```sh
npm run dev
```

全科目をアカウントなしで開き、キーボード操作もONにします。`npm start` の制限は変わりません。APP_ORIGINがlocalhost以外の場合や、販売設定・Stripeキーがある場合は起動しません。公開環境では使わないでください。

## 開発者モード

外部コントローラーがない環境で確認するため、開発者モードではキーボードで操作できます。初期状態では OFF です。

- `W` / `S`: 前後移動
- `A` / `D`: 左右移動
- `E` / `Q`: 上昇 / 下降
- `←` / `→`: 旋回

製品仕様では、飛行訓練は外部コントローラー接続を前提とします。キーボード操作を選ぶと、コントローラーの入力は操縦へ混ぜません。

物理モデルの構成・仮定値・限界は [物理モデル](docs/physics-model.md) を参照してください。

## 解説付き見本と科目別コース

練習メニューの「解説付きの見本を見る」から、コントローラーや登録なしで3科目を観察できます。再生位置と速度は飛行画面の「準備」タブで調整してください。画面左上から操縦者・斜め俯瞰・真上を切り替えられます。
現行の公式図に合わせ、スクエアのHとAを分離し、8の字は中央H、異常事態はHへの高度維持移動と降下を分けています。見本は手順説明用のアニメーションで、操縦の評価や物理モデルの検証結果とは区別しています。

## コントローラーの操作確認

初期版の入力形式はブラウザが `standard` と認識する左右2本・4軸のパッド、Mode 2に限定しています。メーカー名だけで対応を保証していません。実機で確認した機種・PC環境はまだありません。

1. 接続後、パッドのボタンを一度押します。「操作確認と校正を開始」を選び、中央で静止させます。
2. 指示されたスティックだけを端まで動かし、毎回中央へ戻します。左右スティックの上下左右、合計8方向を確認します。
3. 「確認完了」になったら中立へ戻して開始します。設定はこのブラウザへ保存します。次回・再接続時は保存設定の中立を明示的に確認します。違いがあれば8方向から確認し直します。

切断、機器の変更、不正な値、画面離脱では飛行・時間・採点を停止します。練習は操作確認後に再開できます。模擬は中断結果へ進みます。再開時に校正が変わった場合、時刻付きで履歴とログに追記します。旧形式の校正は引き継がず、8方向から確認します。

[入力の検証記録と実機確認の手順](docs/controller-verification.md)

## 本番形式（通し）

練習メニュー（`practice.html`）の「本番形式（通し）」から受付を開きます。全科目と同じ利用権が必要です。`npm run dev` ではローカル開発用に開放されます。無料体験、科目別練習、解説付き見本も引き続き選べます。

受付 → 机上4問 → 空域等の口述 → 部位確認・日常点検記録 → 電源投入・作動点検 → 実操縦の飛行点検 → 実技3科目 → 飛行後点検・飛行記録 → 事故対応2問 → 模擬採点の順です。呼称を選び、ボタンまたはSpaceで試験員へ伝えてください。Spaceは用紙の入力欄・選択欄・ボタンにフォーカスがある間は通常の操作を優先します。各点への到達後にも呼称して次の指示を待ちます。

飛行は操縦者視点に固定し、高度・速度・拡大・経路ガイドを隠します。画面離脱・入力切断は中断結果へ進みます。氏名と記録は実行中のメモリー内だけで扱い、自動保存・送信しません。結果は「模擬採点（公式の合否ではない）」であり、進め方は受験機関の案内を優先してください。

飛行だけを繰り返す場合は、練習メニューの「飛行だけ繰り返す」から飛行点検、スクエア、8の字、異常事態を選びます。受付と口述を省き、本番と同じ画面と採点で1飛行を行います。結果はその飛行の減点のみで、公式の合否ではありません。

要件は [本番再現の仕様](docs/exam-realism-spec.md)、実装上の代理判定と確認の限界は [判断記録 D010](docs/decisions.md#d010本番形式を独立した状態機械として追加する) を参照してください。
