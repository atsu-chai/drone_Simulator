# ドローン国家資格 実地試験対策シミュレーター

二等・マルチローター・基本区分を直接受験する人向けの、ブラウザ版訓練シミュレーターです。検証中であり、公式認定や合格保証は提供しません。

直接受験する利用者の合格実績に向けた現状評価・初期範囲・受入条件は、[要件定義・最低品質基準 v2（提案版）](docs/requirements-v2.md) を参照してください。

## 起動

Node.js 24以上で専用サーバーを起動します（追加パッケージ不要）。

```sh
npm start
```

ブラウザで `http://localhost:8000/index.html` を開きます。

3D描画には Three.js を使っています。Three.js本体と追加ローダーはCDNから読み込むため、初回表示時にネットワーク接続が必要です。機体モデルとHDR環境はリポジトリ内に保存されています。

## 実装済み

- 横画面前提の飛行訓練画面
- Three.js による3D訓練フィールド
- glTF形式の高品質ドローンモデルとプロペラアニメーション
- HDR環境光、ACESトーンマッピング、物理ベースレンダリング
- 操縦者固定位置・斜め俯瞰・真上の3視点
- 科目ごとの色付き区画、四角いH、文字入りコーン（スクエアA〜E・8の字1/2・異常事態E/A/B）
- 飛行前点検の順序チェック
- 練習モード / 本番モードの切り替え
- Gamepad API による外部コントローラー検出
- 標準配置の4軸パッドを使ったMode 2入力、8方向と中立の確認、校正の保存（実機確認済み機種は未確定）
- 13m×5mのA-B-C-D-E-Aスクエア飛行と8分制限
- 直径約5mの8の字飛行2周と8分制限
- 位置安定OFFでの側方1往復、緊急宣言後ホバリング、緊急着陸と6分制限
- 科目ごとのHへの着陸、飛行後点検・飛行記録
- 1Hzの3D再現用JSON飛行ログ
- 120Hz固定時間刻みの機体物理計算
- 推力ベクトル、姿勢応答、重力、空気抵抗、モーター遅延、地面効果
- 通常飛行の位置保持と、異常事態飛行のATTI相当ドリフト
- 高度ブレ、着陸時の流れ、点検ミス、反応時間、課題完了状況を使った独自の練習指標
- 練習状態、独自指標、所要時間、改善点の表示（公式合否は未評価）

## 開発者モード

外部コントローラーがない環境で確認するため、開発者モードではキーボードで操作できます。初期状態では OFF です。

- `W` / `S`: 前後移動
- `A` / `D`: 左右移動
- `E` / `Q`: 上昇 / 下降
- `←` / `→`: 旋回

製品仕様では、飛行訓練は外部コントローラー接続を前提とします。キーボード操作を選ぶと、コントローラーの入力は操縦へ混ぜません。

## 検証版 0.2：サービスと運営機能

Node.js 24以上で、次の専用サーバーを起動してください（追加パッケージ不要）。

```sh
npm start
```

`http://localhost:8000/` で案内ページ、`/index.html` で無料体験、`/learn.html` で教材を開けます。
全科目は登録アカウントの検証利用期間または支払済み契約が必要です。登録後、運営用CLIで検証期間を設定します。

```sh
node server/admin.js grant participant@example.com 45
npm test
npm run check
```

旧プロトタイプと異なり、開発者操作は初期OFF、風表示は無風、結果は公式合否ではなく練習指標です。科目別反復、中断、校正、履歴、航跡を追加しました。
HTTP静的サーバーのみではアカウント・問い合わせ・全科目の権限確認は使えません。上記の専用サーバーを使用してください。

- [実装済みと未検証事項](docs/implementation-status.md)

## 解説付き見本と科目別コース

「解説付きの見本飛行を見る」から、コントローラーや登録なしで3科目を観察できます。科目選択で8の字・異常事態・通しを選び、再生位置と速度を調整してください。画面左上から操縦者・斜め俯瞰・真上を切り替えられます。
現行の公式図に合わせ、スクエアのHとAを分離し、8の字は中央H、異常事態はHへの高度維持移動と降下を分けています。見本は手順説明用のアニメーションで、操縦の評価や物理モデルの検証結果とは区別しています。
[参考動画との対応・残る検証](docs/reference-video-target.md)

## コントローラーの操作確認

初期版の入力形式はブラウザが `standard` と認識する左右2本・4軸のパッド、Mode 2に限定しています。メーカー名だけで対応を保証していません。実機で確認した機種・PC環境はまだありません。

1. 接続後、パッドのボタンを一度押します。「操作確認と校正を開始」を選び、中央で静止させます。
2. 指示されたスティックだけを端まで動かし、毎回中央へ戻します。左右スティックの上下左右、合計8方向を確認します。
3. 「確認完了」になったら中立へ戻して開始します。設定はこのブラウザへ保存します。次回・再接続時は保存設定の中立を明示的に確認します。違いがあれば8方向から確認し直します。

切断、機器の変更、不正な値、画面離脱では飛行・時間・採点を停止します。練習は操作確認後に再開できます。模擬は中断結果へ進みます。再開時に校正が変わった場合、時刻付きで履歴とログに追記します。旧形式の校正は引き継がず、8方向から確認します。

[入力の検証記録と実機確認の手順](docs/controller-verification.md)
