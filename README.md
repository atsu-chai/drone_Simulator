# ドローン国家資格 実地試験対策シミュレーター

仕様書 `drone_spec_v1.txt` をもとにしたブラウザ版プロトタイプです。

直接受験する利用者の合格実績に向けた現状評価・初期範囲・受入条件は、[要件定義・最低品質基準 v2（提案版）](docs/requirements-v2.md) を参照してください。

## 起動

ES Modulesとローカル3Dアセットを読み込むため、HTTPサーバー経由で起動します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/index.html` を開きます。

3D描画には Three.js を使っています。Three.js本体と追加ローダーはCDNから読み込むため、初回表示時にネットワーク接続が必要です。機体モデル、HDR環境、地面テクスチャはリポジトリ内に保存されています。

- 横画面前提の飛行訓練画面

- HDR環境光、ACESトーンマッピング、物理ベースレンダリング
- 草地とアスファルトのPBRテクスチャ
- 操縦者視点に近い追従カメラ
- 四角い着陸パッド、文字入りコーン（A〜E・1/2・F/G/H）、ゲート、フェンス、周辺建物
- 飛行前点検の順序チェック
- 練習モード / 本番モードの切り替え
- Gamepad API による外部コントローラー検出
- Switch / PlayStation / Xbox / 汎用向けプリセット選択
- 13m×5mのA-B-C-D-E-Aスクエア飛行と8分制限
- 直径約5mの8の字飛行2周と8分制限
- 位置安定OFFでの側方1往復、緊急宣言後ホバリング、緊急着陸と6分制限
- 科目間のA点着陸、飛行後点検・飛行記録
- 1Hzの3D再現用JSON飛行ログ

- 推力ベクトル、姿勢応答、重力、空気抵抗、モーター遅延、地面効果

- 高度ブレ、着陸時の流れ、点検ミス、反応時間、課題完了状況を使った独自の練習指標
- 練習状態、独自指標、所要時間、改善点の表示（公式合否は未評価）

## 開発者モード

外部コントローラーがない環境で確認するため、開発者モードではキーボードで操作できます。初期状態では OFF です。

- `W` / `S`: 前後移動
- `A` / `D`: 左右移動
- `E` / `Q`: 上昇 / 下降
- `←` / `→`: 旋回

製品仕様では、飛行訓練は外部コントローラー接続を前提とします。

## 検証版 0.2：サービスと運営機能

Node.js 24以上で、次の専用サーバーを起動してください（追加パッケージ不要）。

```sh
npm start
```

`http://localhost:8000/` で案内ページ、`/index.html` で無料体験、`/learn.html` で教材を開けます。
全科目は登録アカウントの検証利用期間または支払済み契約が必要です。登録後、運営用CLIで検証期間を設定します。

```sh
node server/admin.js grant participant@example.com 45
npm test
npm run check
```

旧プロトタイプと異なり、開発者操作は初期OFF、風表示は無風、結果は公式合否ではなく練習指標です。科目別反復、中断、校正、履歴、航跡を追加しました。
HTTP静的サーバーのみではアカウント・問い合わせ・全科目の権限確認は使えません。上記の専用サーバーを使用してください。

- [実装済みと未検証事項](docs/implementation-status.md)
- [募集・実機評価・受験追跡・採算の運営手順](operations/README.md)
- [公式要件との対応と監修課題](docs/official-mapping.md)
- [決済・公開環境の準備](docs/billing-setup.md)

初月10,000円、翌月以降3,000円の課金処理は実装していますが、標準設定では販売停止です。監修・実績・決済検証・販売者情報等を確認するまで停止を解除しないでください。秘密鍵、DB、記入済みの個人情報はGitに保存しないでください。
